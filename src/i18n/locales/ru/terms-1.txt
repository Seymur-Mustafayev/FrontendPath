@@ term.dom.tr
Объектная модель документа

@@ term.dom.def
Представление HTML в памяти браузера в виде дерева объектов. JavaScript изменяет страницу именно через это дерево.

@@ term.cssom.tr
Объектная модель CSS

@@ term.cssom.def
Преобразование браузером всех CSS-правил в дерево объектов; вместе с DOM образует render tree.

@@ term.render-tree.tr
Дерево рендеринга

@@ term.render-tree.def
Объединение DOM + CSSOM; содержит только элементы, которые будут видны на экране (элементы с display:none не входят).

@@ term.reflow.tr
Перерасчёт раскладки

@@ term.reflow.def
Повторный расчёт браузером всего layout при изменении размера или позиции элемента — дорогая операция.

@@ term.repaint.tr
Перерисовка

@@ term.repaint.def
Только визуальные изменения вроде цвета/тени — layout не пересчитывается, поэтому дешевле reflow.

@@ term.critical-rendering-path.tr
Критический путь рендеринга

@@ term.critical-rendering-path.def
Шаги от получения HTML до появления первого пикселя на экране; сократить их = сайт, который быстро открывается.

@@ term.http.tr

@@ term.http.def
Правила «запрос–ответ» между браузером и сервером. Методы: GET, POST, PUT, PATCH, DELETE.

@@ term.https.tr

@@ term.status-code.tr

@@ term.status-code.def

@@ term.http-header.tr

@@ term.tls.tr

@@ term.dns.tr

@@ term.dns.def

@@ term.cdn.tr

@@ term.cdn.def
Сеть, которая отдаёт статические файлы с серверов, географически близких к пользователю; резко снижает задержку.

@@ term.hosting.tr

@@ term.client-server.tr

@@ term.rest.tr

@@ term.endpoint.tr

@@ term.json.tr

@@ term.devtools.tr

@@ term.network-tab.tr

@@ term.breakpoint.tr

@@ term.semantic-html.tr

@@ term.landmark.tr

@@ term.form-validation.tr
