@@ exam.ydkjs-scope.ch5.3.q
According to the book, what should the term "hoisting" really refer to?

@@ exam.ydkjs-scope.ch5.3.o0
The JS engine physically re-arranging the code before execution

@@ exam.ydkjs-scope.ch5.3.o1
The compile-time generation of instructions that automatically register a variable at the beginning of its scope, each time the scope is entered

@@ exam.ydkjs-scope.ch5.3.o2
Moving variables into the global scope

@@ exam.ydkjs-scope.ch5.3.o3
Placing functions at higher memory addresses

@@ exam.ydkjs-scope.ch5.3.why
The engine doesn't re-arrange code — to find the declarations it has to fully parse the code, which is the first phase of two-phase processing. Hoisting should be thought of as a compile-time task.

@@ exam.ydkjs-scope.ch5.8.q

@@ exam.ydkjs-scope.ch5.8.o0
`const` only works in the global scope

@@ exam.ydkjs-scope.ch5.8.o1
`const` always requires an assignment and can't be re-assigned — a re-declaration would also be a re-assignment

@@ exam.ydkjs-scope.ch5.8.o2

@@ exam.ydkjs-scope.ch5.8.o3
The reason is purely stylistic

@@ exam.ydkjs-scope.ch5.8.why
A `const` without an assignment is a `SyntaxError`, and assigning a new value to a `const` is a `TypeError`. So any repeated `const` declaration would be a forbidden re-assignment.

@@ exam.ydkjs-scope.ch5.10.q
Why doesn't writing `let value = ...` inside a `while` loop throw a re-declaration error on every iteration?

@@ exam.ydkjs-scope.ch5.10.o0
`let` automatically turns into `var` in loops

@@ exam.ydkjs-scope.ch5.10.o1
Each iteration is a new scope instance, and `value` is declared only once in each instance

@@ exam.ydkjs-scope.ch5.10.o2
Scope rules don't apply in loops

@@ exam.ydkjs-scope.ch5.10.o3
JS hides re-declaration errors in loops

@@ exam.ydkjs-scope.ch5.10.why
Scope rules are applied per scope instance: every time a scope is entered during execution, everything resets. Mentally erasing the declarator keywords helps you see this.

@@ exam.ydkjs-scope.ch5.11.q

@@ exam.ydkjs-scope.ch5.11.o0
The outer (e.g. global) scope, once

@@ exam.ydkjs-scope.ch5.11.o1
The loop body's scope — with its own `i` on each iteration

@@ exam.ydkjs-scope.ch5.15.q

@@ exam.ydkjs-scope.ch5.15.o0

@@ exam.ydkjs-scope.ch5.15.o1
