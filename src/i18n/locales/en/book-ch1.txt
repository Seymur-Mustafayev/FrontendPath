The chapter in summary — four rules

@@ sec.ydkjs-scope.ch1.lexical-scope.code7
1. var           → bound to the nearest FUNCTION
2. let / const   → bound to the nearest { } BLOCK
3. A variable that isn't found → looked up one level out (the scope chain), up to the global scope
4. Not found anywhere          → "undeclared" → usually a ReferenceError
