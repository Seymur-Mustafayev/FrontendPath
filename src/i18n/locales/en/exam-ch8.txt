@@ exam.ydkjs-scope.ch8.4.q

@@ exam.ydkjs-scope.ch8.4.code

})();

@@ exam.ydkjs-scope.ch8.4.o0

@@ exam.ydkjs-scope.ch8.4.o1

Everything inside the module definition function is private by default. Only what's added to the returned public API object is exposed, and those functions hold closures over the hidden state.
